# Iris

Iris는 첫 기능의 범위를 정하는 단계에 있습니다.

## 첫 버전 계획

- [ ] 프로젝트가 해결할 문제와 사용할 사람을 한 문장으로 정한다.
- [ ] 그 사람이 처음부터 끝까지 해 볼 수 있는 기능 하나를 고른다.
- [ ] 해당 기능을 구현하고 실행 방법을 이 문서에 적는다.
- [ ] 새로 받은 환경에서 문서의 순서대로 실행해 보고 결과를 기록한다.

## 변경 제안 방법

`main`에서 작업 브랜치를 만들고, 변경 사항을 커밋한 다음 Pull Request를 연다. PR 설명에는 변경 이유와 확인한 내용을 적는다.
