# Iris 쿠션 챌린지

하나부터 세 번까지 쿠션을 활용해 금색 표적에 닿는 브라우저 당구 퍼즐입니다. 여섯 배치를 원하는 순서로 플레이할 수 있습니다.

## 실행

[ZIP 다운로드](https://github.com/archendel/Iris/archive/refs/heads/docs/iris-kickoff.zip) 후 압축을 풀고 `index.html`을 브라우저에서 엽니다. 설치와 서버 실행이 필요 없습니다.

## 플레이

- 테이블을 누르거나 방향 슬라이더를 움직여 조준하고, 세기를 골라 샷을 칩니다.
- 성공 경로 찾기는 실제 샷의 물리 계산을 사용해 각도와 세기를 탐색하고, 예상 경로와 쿠션 지점을 표시합니다.
- 슬로모션 다시 보기로 방금 친 샷을 0.4배속으로 확인합니다.
- 완료 여부와 최소 샷 기록은 브라우저 저장소가 허용될 때 해당 브라우저에 저장됩니다. 힌트를 사용한 샷도 기록에 포함됩니다.
