# Iris · 원쿠션 연습실

쿠션에 맞고 돌아오는 공의 경로를 연습하는 브라우저 게임입니다.

## 실행 방법

저장소를 내려받아 `index.html`을 브라우저에서 엽니다. 별도 설치나 서버 실행이 필요 없습니다.

## 조작

1. 테이블을 누르거나 방향 슬라이더를 움직여 조준합니다.
2. 세기를 조절하고 **샷**을 누릅니다.
3. 흰 공이 쿠션을 한 번 이상 맞힌 뒤 금색 표적에 닿으면 성공입니다. **다시 놓기** 버튼으로 진행 중인 샷을 취소할 수 있습니다.

## 확인한 동작

게임 스크립트에서 쿠션을 한 번 맞힌 뒤 성공하는 샷, 표적에 바로 닿는 샷, 표적에 닿지 않고 멈추는 샷, 샷 진행 중 초기화를 확인했습니다.
